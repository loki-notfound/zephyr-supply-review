Scoped to the EVM bridge only: the smart contracts plus the off-chain bridge API/watchers. Not the L1.

Reasoning: the bridge is genuinely new code. Contracts, relayers, cross-chain state syncing =  the new attack surface we've introduced by going cross-chain.

The L1 is built on Minimal Djed (the formally verified Cardano/IOHK) sitting on top of Monero's cryptography (ring sigs, stealth addresses, bulletproofs), which has years of production hardening behind it already.

So, different risk profile/priority right now (new code gets audited first).

That's not to say we'll never look at the L1... as the protocol scales, a dedicated L1-focused review is a reasonable step. Right now the bridge is where the actual new risk lives, so that's where the audit spend goes first.
